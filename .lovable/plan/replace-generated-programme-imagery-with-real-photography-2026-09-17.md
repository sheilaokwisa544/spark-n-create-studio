# Replace Generated Programme Imagery with Real Photography

## Scope
- Replace all generated imagery used by Art Club, Crochet Club, Fashion & Design Club, and AI for Teens.
- Keep the existing ChoraNami layout, branding, copy, navigation, and interactions unchanged.
- Preserve the ten supplied real ChoraNami photographs and continue using them only where they accurately depict the activity.

## Photography selection
- Source real, commercially usable photographs from reputable royalty-free libraries such as Unsplash, Pexels, and Pixabay.
- Select a distinct, strong hero photograph for each programme.
- Add supporting photographs for project cards and gallery fallbacks that visibly match each activity.
- Reject watermarked, artificial-looking, generic corporate, heavily edited, or irrelevant images.
- Keep a source-and-license record in the project for every third-party photograph.

## Implementation
- Download selected originals and store them through the project’s managed asset service.
- Centralize the new photo references and update programme cards, dedicated programme heroes, projects, and fallback galleries.
- Remove references to generated programme images; leave unrelated site imagery untouched.
- Use descriptive alternative text and retain lazy loading for supporting imagery.

## Verification
- Check all four dedicated programme pages, the main Programmes page, and homepage programme cards.
- Confirm each image loads, matches its programme, crops cleanly on desktop and mobile, and is not repeated across unrelated programmes.
- Confirm all existing programme links, galleries, and calls to action still work and the preview reports no errors.
